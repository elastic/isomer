<h1 align="center">@elastic/isomer-primitives-vega</h1>
<p align="center"><strong>isomer</strong> <i>n.</i> — one formula, many forms; the same composition rendered to every surface.</p>
<!-- markdownlint-enable MD033 -->

A primitive pack with one node, `vega`: a Vega or Vega-Lite spec with inline data, drawn by the Vega runtime on every surface, with the charts pack's node conventions.

```ts
import { vegaPack } from '@elastic/isomer-primitives-vega';
import { vegaSchema } from '@elastic/isomer-primitives-vega/schema';
```

Read the [documentation](https://github.com/elastic/isomer/blob/main/packages/isomer-primitives-vega/docs/index.md).
