<h1 align="center">@elastic/isomer-charts-elastic-static</h1>
<p align="center"><strong>isomer</strong> <i>n.</i> — one formula, many forms; the same composition rendered to every surface.</p>
<!-- markdownlint-enable MD033 -->

A `SceneRenderer` that draws Isomer chart Scenes (`metric`, `xy`, `partition`) as static SVG with Elastic Charts, on Node or in static markup, so the `snapshot` surface carries them to an image backend for PNG and PDF.

```ts
import { createElasticChartsStaticRenderer } from '@elastic/isomer-charts-elastic-static';
```

Read the [documentation](https://github.com/elastic/isomer/blob/main/packages/isomer-charts-elastic-static/docs/index.md).
