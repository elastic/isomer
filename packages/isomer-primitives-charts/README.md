# Isomer charts

`@elastic/isomer-primitives-charts` supplies the portable `metricTrend` model,
primitive, theme and nonvisual adaptations. It does not import Elastic Charts,
Lens, Kibana, a query executor or a rasterizer.

Read the [contract and API](docs/index.md) and [semantic inventory](docs/metric.md).
Use `@elastic/isomer-renderers-elastic-charts`
for mounted Elastic Charts browser rendering.
