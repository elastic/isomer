# Elastic Charts engine

`@elastic/isomer-charts-elastic` draws [chart Scenes](../charts/scene.md) with [Elastic Charts](https://github.com/elastic/elastic-charts), the library Kibana draws its panels with, so a chart in a browser host looks like the Kibana panel it came from. It is a `SceneRenderer` for the browser and supports the `metric`, `xy`, `partition`, `heatmap`, `gauge` and `tagCloud` kinds. Kibana draws a [`legacyMetric`](../charts/legacy-metric.md) without Elastic Charts, so the charts pack draws that kind itself, as it does a table.

```sh
npm install @elastic/isomer-charts-elastic @elastic/charts moment moment-timezone react react-dom zod
```

```ts
import { createElasticChartsRenderer } from '@elastic/isomer-charts-elastic';
import '@elastic/charts/dist/theme_light.css';

const renderer = createElasticChartsRenderer();
renderer.render(scene, { environment: 'browser', nodeId: node.id, onEvent });
```

The page needs Elastic Charts' stylesheet for the Scene's scheme, `theme_light.css` or `theme_dark.css`; without it a chart measures zero and draws nothing. Kibana always loads it. A chart drawn in a shadow root needs the stylesheet inside that root, and on the document too: Elastic Charts portals its own xy tooltip to `document.body`, while this engine's secondary-metric tooltip stays in the chart's root.

The few elements this engine draws beside Elastic Charts' own, a metric's secondary text without a badge and its tooltip, the legend's filter buttons, and an empty chart's note, take classes from the charts pack's distillery (`chartsElastic-*`), with what only the Scene knows in Distillate vars. Through the runtime, the pack's style adapter emits their rules; a host that draws the `react` surface itself ships `chartsStylesheet()` and `elasticChartsStylesheet()` beside Elastic Charts' stylesheet. `elasticChartsStylesheet()` holds this engine's rules alone and needs nothing loaded first, so a host that builds its CSS before it loads the engine, such as one that code-splits it, still gets them.

`@elastic/charts`, React and React DOM are peer dependencies, so a host shares its own copy: Kibana's pin is the version this engine is tested against (`ELASTIC_CHARTS_VERSION`).

## One spec builder

`sceneSpecs(scene, env, options?)` turns a `metric`, `xy`, `partition`, `heatmap`, `gauge` or `tagCloud` Scene into Elastic Charts spec elements: `Settings`, axes, series, reference lines and annotations in the Scene's layer order, the metric grid, a `Partition` of the Scene's slices, a `Heatmap` of its cells, a gauge's `Bullet`, or a `Wordcloud` of its words. The renderer wraps them in `<Chart>`; headless drawing hands the same elements to Elastic Charts' `collectSpecs`, so a chart drawn in a browser and one drawn on a server come from one place.

`@elastic/isomer-charts-elastic/engine` exports `sceneSpecs` and what else another Elastic Charts drawing of a Scene builds on: `kibanaBaseTheme`, `ariaDescriptionOf`, `emptyTextOf` and its text sizes, `seriesOf`, `slicesOf`, and `TAG_CLOUD_LABEL`, the tag cloud label's type. A drawing that collects the specs must build them from the same copy of `@elastic/charts` it collects with.

## What it takes from the Scene

Colors, text and series are the Scene's, and draw order is as far as Elastic Charts' paint bands allow (see the tolerance table). Ticks, domains, stacks and point density are Elastic Charts', computed from the intent each Scene axis and series states, the way Kibana's xy expression hands them over. A tick label prints through `formatAxisValue`, so it reads the same in every engine. A time x axis with `timeTicks` is Elastic Charts' multi-layer time axis, as Lens draws it: Elastic Charts takes no ticks from outside, so it picks and labels them itself, from the same domain, bucket, time zone and locale the resolver used, and `debugStateProblems` holds what it draws to the Scene's [time ticks](../charts/scene.md#time-axes).

## Events

With `onEvent` and a node id, a gesture raises the event of the Scene part it lands on, through the Scene's [selections](../charts/scene.md#selections-and-events). Elastic Charts' own indexes and values are never used.

| Gesture                                                     | Elastic Charts callback                                     | Event                                               |
| ----------------------------------------------------------- | ----------------------------------------------------------- | --------------------------------------------------- |
| Click a bar, point or area vertex                           | `onElementClick` (the first element, as Kibana takes it)    | `datum`; `category` when the node offers no `datum` |
| Click the plot away from a mark                             | `onProjectionClick`                                         | `category`: the x position the click falls in       |
| Drag along a continuous x axis                              | `onBrushEnd`                                                | `brush`                                             |
| "Filter for" or "Filter out" beside a legend item           | Legend action                                               | `legend`, with `negate` for "Filter out"            |
| Click a metric tile                                         | `onElementClick`                                            | `tile`                                              |
| Click a partition slice                                     | `onElementClick` (the innermost slice of the first element) | `slice`                                             |
| "Filter for" or "Filter out" beside a partition legend item | Legend action                                               | `slice`, with `negate` for "Filter out"             |
| Click a heat map cell                                       | `onElementClick` (the first cell, by its datum)             | `cell`                                              |
| Drag across a heat map's time axis                          | `onBrushEnd`                                                | `brush`                                             |
| Click a tag cloud word                                      | `onElementClick` (the word, by its datum)                   | `tag`                                               |

Clicking a legend item's label toggles its series, which raises nothing.

`src/parity.test.ts` holds the engine to this table over every example the charts pack has, nested in a `grid` or not: each gesture above, built from what Elastic Charts reports for it and sent to the callbacks and legend action the specs install on `Settings`, raises the event of the Scene part it lands on, through `selectEvent` and `brushEvent`, and nothing where the node offers no target. No metric example offers `tile`, so each is also checked offering it.

`src/time_axis.test.ts` holds the Scene's time ticks to Elastic Charts' own: for intervals from 100 ms to a year, zones with and without daylight saving (New York both ways, Berlin, Kolkata, Santiago's midnight gap, Lord Howe's half hour), several locales, bars and lines, and widths from 40 to 2,400 pixels, `multilayerAxisEntry` picks the same ticks, labels, rows and grid flags as the Scene's band at that width.

## Testing a static drawing

`@elastic/isomer-charts-elastic/testing` holds what any static drawing with Elastic Charts checks beside the charts pack's [static renderer checks](../charts/rendering.md#testing-a-static-renderer):

- `debugStateProblems(scene, state)` compares the `DebugState` Elastic Charts reports for a drawing with its Scene: every tick label is the category's label, a label the Scene's `timeTicks` give that value on a time axis, or the value through `formatAxisValue`, the series drawn and the legend items are the Scene's with their colors, a partition draws each slice by key with its color and value, and a heat map draws each cell in its band's color with its value text, and no value without `cellLabels`, its positions' labels, its axis titles and its bands as the legend, and a gauge draws its bullet with the Scene's labels, value, goal, scale, bands and ticks. A metric or tag cloud has no `DebugState`, so it is checked by its text alone. `debugStateTexts` and `debugStateColors` read what it reports as drawn, for an engine whose output holds no text or paint to read.
- `defineLookSuite({ test, expect, drawn, script, stylesheet, sameScene, looser?, unlike })` declares the look check in Chromium, given Playwright's `test` and `expect`: this engine's browser drawing of each Scene is the static drawing's size and scores a mean SSIM, on luminance at an eighth of their size (`LOOK_SCALE`) with every pixel counted, of at least `sameScene[kind]` against the static drawing of the same Scene, and below it against the static drawing of each of the `unlike` pairs, examples established to differ in layout. `script` is a bundle that calls `installLookPage()`, which draws Scenes with this engine and scores pictures in the page. `onScore`, when given, receives every score with its tolerance, for an engine to record.

`src/testing.test.ts` holds `debugStateProblems` to what this engine draws for every xy, partition, heat map and gauge example in jsdom, and to mutations of it: a changed tick label, a series in another color, a slice missing, a cell in another color or with another value, a gauge with another value or band.

## Known gaps and geometry tolerance

Content (strings, colors, order) is the Scene's. Where Elastic Charts cannot take a value from the Scene, its layout or a feature differs from the Scene:

| Kind      | Gap                                                                                                                                                                                                                                                                                                                                                     | Effect                                                                                                                       |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| xy        | Series stack by axis: Elastic Charts has no stack group, so two stacked layers on one axis stack together                                                                                                                                                                                                                                               | Matches Kibana; differs from the Scene's `stack.group`                                                                       |
| xy        | Bars on a continuous x axis use histogram mode when stacked or alone, as Kibana's rule is; the Scene does not state it                                                                                                                                                                                                                                  | Bar placement follows Kibana's rule, not the Scene                                                                           |
| xy        | `legend.items[].statistics` are not drawn                                                                                                                                                                                                                                                                                                               | Legend statistics missing                                                                                                    |
| xy        | `legend.items[].hidden` is not applied: Elastic Charts has no public initial deselection                                                                                                                                                                                                                                                                | Hidden series draw until a reader toggles them                                                                               |
| xy        | Annotation and reference-line icons and text markers are not drawn                                                                                                                                                                                                                                                                                      | Lines and fills only                                                                                                         |
| xy        | `currentTime` is not drawn: the Scene gives it no color                                                                                                                                                                                                                                                                                                 | No current-time marker                                                                                                       |
| xy        | `interactions.emphasis` and `sync` are not drawn                                                                                                                                                                                                                                                                                                        | No static highlight or synced cursor                                                                                         |
| xy        | No gesture raises the `series` select target; legend actions raise `legend`                                                                                                                                                                                                                                                                             | A node offering `series` raises nothing for it                                                                               |
| xy        | `partial` marks are not shaded                                                                                                                                                                                                                                                                                                                          | No end-zone shading                                                                                                          |
| xy        | Elastic Charts paints in fixed bands: annotations beneath the series, then bars, areas and lines, then annotations above. A reference line or point annotation between two series paints above both, a range after a series paints beneath it, and series of different marks paint bars first, then areas, then lines, whatever their order in `layers` | Overlap between layers can differ from the Scene's order                                                                     |
| metric    | `layout.icon` is not drawn: Elastic Charts takes an icon component, and this engine maps no `ChartGlyph` to one                                                                                                                                                                                                                                         | No tile icon                                                                                                                 |
| metric    | `trend.xDomain` and `trend.yDomain` are not applied: Elastic Charts fits the trend to its points                                                                                                                                                                                                                                                        | Trend line scale may differ                                                                                                  |
| metric    | Title and subtitle colors are Elastic Charts' contrast choice against the tile background                                                                                                                                                                                                                                                               | Title color may differ from the Scene's `chrome.text`                                                                        |
| metric    | A progress bar draws `progress.fraction` against a domain of 1                                                                                                                                                                                                                                                                                          | Bar length matches; Elastic Charts' accessible progress text reads the fraction                                              |
| partition | Slice label text color is Elastic Charts' contrast choice against each fill                                                                                                                                                                                                                                                                             | Label color may differ from the Scene's `chrome.text`                                                                        |
| partition | A legend value is found by the slice's sum alone, so where legend items with one sum carry different `valueText`s (several metrics in different formats), none of them shows a legend value                                                                                                                                                             | Those legend values are missing rather than another slice's                                                                  |
| partition | `interactions.emphasis` is not drawn                                                                                                                                                                                                                                                                                                                    | No static highlight                                                                                                          |
| heatmap   | Cell label text color is Elastic Charts' contrast choice against each fill                                                                                                                                                                                                                                                                              | Label color may differ from the Scene's `chrome.text`                                                                        |
| heatmap   | A cell label's formatter sees only the value, so where cells share a value but carry different `valueText`s, none of them is labelled                                                                                                                                                                                                                   | Those cell labels are missing rather than another cell's                                                                     |
| heatmap   | A time axis is drawn from the first instant to the last bucket's end, a column per `interval`, with ticks Elastic Charts chooses                                                                                                                                                                                                                        | Columns with no row draw empty; tick placement may differ                                                                    |
| heatmap   | `interactions.emphasis` and `sync` are not drawn                                                                                                                                                                                                                                                                                                        | No static highlight or synced cursor                                                                                         |
| gauge     | The value bar, tick and text colors are Kibana's bullet theme's, not the Scene's chrome                                                                                                                                                                                                                                                                 | Matches Kibana; differs from `chrome.text`                                                                                   |
| gauge     | A circle's last tick lies on its first, and Elastic Charts draws only the first                                                                                                                                                                                                                                                                         | The `max` tick label is missing on a circle                                                                                  |
| tagCloud  | Elastic Charts places words by pixel sprites each engine measures its own way, so words land in different places, and a word that fits in one may not in the other                                                                                                                                                                                      | Word placement differs; the look gate compares colors' mass, not layout, and holds a cloud of many small turned words to 0.6 |
| tagCloud  | Words that do not fit are left out with no note: Kibana shows a warning icon                                                                                                                                                                                                                                                                            | No out-of-room warning                                                                                                       |
| tagCloud  | `interactions.emphasis` is not drawn                                                                                                                                                                                                                                                                                                                    | No static highlight                                                                                                          |
| all       | Pixel layout (margins, label placement, legend width)                                                                                                                                                                                                                                                                                                   | Geometry compared within tolerance, not exactly                                                                              |

`link` is drawn by the primitive around the renderer, not inside the chart.
