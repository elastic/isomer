# Directory Update Log

## 2026-09-29

- **Markdown builder gaps**: `md` adds `blockquote(...blocks)`, which quotes builder blocks and embedded child content and drops a quote with none, and `break()`, a hard break printed as a backslash before the line ending; a break at the start or end of a paragraph, heading, strong, emphasis, link label, or table cell is dropped, and one elsewhere inside any of these but a paragraph prints as a space. A `md.table` cell takes one inline run or an array of them. `md.boldLabelPrefix(text, label)` and `md.boldSectionLabel(label)` build the label helpers' output as content, escaping the text too, and the string `boldSectionLabel` prints the builder form. `@elastic/isomer-sdk/author` exports `oneLine`. Builder content reaches Slack from its tree: a quote is one level, its text a `rich_text_quote` and a list or code block it holds bordered, a quote in a list item gives the item its blocks, and a hard break is a line break. When a block goes through the string translator, a hard break reaches it as a line ending and a quote as its blocks, and Markdown printed as written inside a quote comes back quoted line by line. GFM fidelity for string results is #80.
- **Slack fallback from builder content**: A primitive without a `slack` renderer whose `markdown` renderer returns `md` content reaches Slack through `markdownContentToSlackBlocks`, from the tree rather than re-parsed Markdown: paragraphs, headings, lists, and code as `rich_text` with literal text and style flags, so nothing is escaped and nesting survives exactly, and tables as `table` blocks with rich-text cells where formatted. Markdown printed as written, and a list holding a block a rich-text list item cannot, such as a table, keep the string translator; a table with no columns prints nothing and a row with no cells is dropped. The string translator's line-by-line and delimiter-nesting limits are documented. `SlackRichTextList` gains `offset`.
- **Markdown builder**: `@elastic/isomer-sdk/markdown` adds `md`, which builds Markdown as content, and `serializeMarkdown`, one GFM serializer over `mdast-util-to-markdown` and `mdast-util-gfm` that escapes each value where it lands and reapplies the URL policy at serialization. A `markdown` renderer may return `MarkdownContent` or a string; the dispatcher serializes content per node, `renderMarkdown` and the runtime's `renderNode` still return strings, and `RenderScope.renderMarkdownContent` nests a child as content, printing a string result as written. `boldLabelPrefix` and `boldSectionLabel` escape their label. Empty `strong`, `emphasis`, and `code` print nothing, and printed-as-written content drops trailing whitespace. The Slack fallback reads single-asterisk emphasis as italics under GFM's flanking and escape rules, translates the inside of bold and italic so they nest, prints an image as a link to its source and a link label or table cell as plain text, opens a code fence only as GFM does and closes one on a CRLF line, single-column tables as tables, and closes a code fence only on one at least as long. The packed-consumer check links every packed package's dependencies before importing any, and the license report matches license and notice files case-insensitively.
- **Takumi `pdf`**: `createTakumiImageBackend` gains `pdf(input, options?)`, which takes the `svg` surface's `renderPages` result (`PdfInput`) and writes one page per root at the input's size with no margin, vector with the registered fonts embedded, on a `takumi-pdf` engine imported and created on the first PDF with the same fonts, so a raster-only host never loads it. `TakumiPdfOptions` passes through `metadata`, `uncoveredText`, `images`, `outline`, `lang`, and `backgroundColor`; a glyph no registered font covers rejects the render by default, and a remote `img` draws only from bytes given in `images`. `createTakumiImageBackend` now returns `TakumiBackend`, which adds `pdf` to `TakumiMeasuringBackend`; `TakumiPdfBackend` is `{ pdf }`, `renderPdf(runtime, deck, backend, options?)` mirrors `renderPng` over a deck, and `TakumiImageBackend`, `TakumiMeasuringBackend`, and `renderPng` are unchanged. The slides deck registers `@fontsource/noto-sans-symbols-2` last for its `✓` and `✕` markers and commits `deck.pdf` beside its PNGs.
- **Slides `check` and `x` markers render**: the bullet list's `dot` marker is a variant like `check` and `x`, so no marker rule is overridden by `root` at equal specificity; the two glyphs had never reached any surface. The bullets `root` rule no longer sets `content`.
- **`renderPages` on the svg surface**: `runtime.surfaces.svg.renderPages(compositions, options?)` lays several compositions out under one frame with one stylesheet collected across every page and returns `SvgPagesResult`, `{ pages, css, width, height }`; every page is the tallest estimate unless `height` is given, the first composition's `theme` decides the palette unless `theme` is given, a body the frame rejects names its page (one-based), and an empty list throws the new `EMPTY_PAGES` code. `render` is now one page of the same path.
- **`measureDom`**: The SDK adds `measureDom(root)`, the `LayoutBox` tree a browser laid an element out as, measured from its top left, so a React or HTML host can hand a rendered composition to `checkLayout` with `'react'` as its surface.
- **Slack fallback reads GFM escapes**: `gfmToSlackMrkdwn` and `gfmToSlackBlocks` read a backslash escape or a numeric character reference as the character it stands for, in prose, emphasis, link labels and destinations, headings, and table cells. Code spans keep their backslashes, except before a pipe in a table cell. An escaped delimiter is never converted to formatting, though Slack may still format a literal pair itself, and a table row splits only on unescaped pipes. A destination is decoded before the URL policy reads it. An escaped `)` or closing `#` stays text, a table pipe after an even run of backslashes splits, `gfmToSlackMrkdwn` decodes fenced table cells too, and a control-character reference decodes to U+FFFD as micromark does. Code spans pair backtick runs of equal length, so a double-backtick span keeps its escapes, and fenced output goes through `codeBlock`, so a decoded fence cannot close it. `link` percent-encodes a `|` in the URL. Translation is linear in the line's length, including code-span fences of many distinct lengths.
- **Node 22.13.0 floor**: The SDK, runtime, evals, and workspace root declare `engines.node` `>=22.13.0`. CI verifies on that exact version beside the latest 22 and 24, and the packed-consumer check fails on any process warning.
- **Layout check**: The SDK adds `checkLayout(layout, body, walk, surface)`, which pairs a measured `LayoutBox` tree with a body's nodes through their anchors and returns advisory `LayoutFinding`s for a node past its nearest anchored ancestor or the canvas, and for siblings that land on each other. `withNodeAnchors(context)` turns anchors on for a context, and the runtime's `svg` surface takes `anchors` on `render` and `renderNode`.
- **Takumi `measure`**: `createTakumiImageBackend` returns a `TakumiMeasuringBackend` whose `measure(input)` lays the input out as `png` would and returns a `LayoutBox` tree of canvas boxes, axis scales, text runs, and each element's attributes, so a node anchor comes back on its box. `TakumiImageBackend` and `renderPng` are unchanged.
- **Own keys in the authoring schema**: `buildAuthoringJsonSchema` reads and writes only own keys, so a `describe` entry, def id, or property named `__proto__` never reaches `Object.prototype` or drops out of the schema.
- **Slack envelope clamps every block's text**: `renderSlackEnvelope` clamps each Slack-limited text in the blocks a renderer returns, not just asset-image alt text. `SLACK_LIMITS` gains `imageTitleChars`, `videoTitleChars`, `videoDescriptionChars`, `videoAuthorNameChars`, `buttonTextChars`, `placeholderChars`, and `optionGroupLabelChars`. `clampSlackText` cuts at a grapheme boundary, so it never splits a surrogate pair or emoji sequence.
- **Releases follow published packages**: The workspace semantic-release plugin runs the commit analyzer and notes generator over only the commits that change a package published now or at the last release, a root build input, the root `build` scripts, or a published package's reference in `tsconfig.workspace.json`, so slides-pack, docs, and tooling commits no longer cut a release. The publish playbook lists all four published packages.
- **`!` marks a breaking change**: `.releaserc.json` adds a `breakingHeaderPattern` to the angular preset's parser options, so a `feat!:` or `fix(scope)!:` header drives a major release and lands under breaking changes in the notes without a `BREAKING CHANGE` footer.

## 2026-09-28

- **Enhancements on the React surface**: `ReactRenderOptions.enhancements` takes enhancement definitions; those that apply reach every renderer as `context.enhancements`, turn node anchors on when one asks, and run their scripts against the wrapper section once it mounts. The SDK's React entry adds `applyEnhancements`, and `findNodeElementPairs` lists each node occurrence with its anchored element, so a node object used twice pairs twice. The embedding doc covers a React host with a Distillate live collection, and the slides pack takes `@elastic/distillate` `^0.2.0`.
- **Unique JSX component names**: `buildJsxShim` throws `DUPLICATE_PRIMITIVE_TYPE`, naming both types, when two primitive or child types capitalize to one component name or a type collides with the root `Composition`.
- **`toComposition` keeps `version`**: The JSX shim carries the root element's `version` onto the composition alongside `title`, `subtitle`, `theme`, and `meta`.
- **Validation errors name their node**: `ValidationError` gains `nodeType`, the innermost primitive node its path lands in, set by the parser, the validator, the duplicate-id pass, and a dispatcher's `validate`. `formatValidationError` prints `<path> (in <nodeType>) <message>`, and an unknown key on a node lists that node's declared fields. Names and ids a finding echoes are JSON-quoted when not plain, with line terminators escaped.
- **`heading` on text, markdown, and slack**: `renderTextEnvelope`, `renderMarkdownEnvelope`, and `renderSlackEnvelope` take `heading` (default `true`) through the new `TextEnvelopeOptions` and `MarkdownEnvelopeOptions` and the existing `SlackEnvelopeOptions`; `false` leaves out the title and subtitle, and Slack's fallback `text` with them. The runtime's `TextRenderOptions` and `MarkdownRenderOptions` extend those types, and `SlackRenderNodeOptions` omits `heading`.
- **Index catalog and primitive lookups**: A pack declares `authoring.groups`, the authoring prompt prints `catalog: 'index'` as one line per primitive under those groups with `schema` optional, and the runtime's authoring context adds `groups` and `describePrimitives(types)`, backed by the SDK's `authoringSchemaSubset` and `formatPrimitiveEntry`. Every catalog and registered-view line collapses line terminators, and each code span is fenced longer than any backtick run inside it.
