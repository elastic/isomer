# Changelog

Release notes live on the [GitHub Releases](https://github.com/elastic/isomer/releases) page, generated from [conventional commits](https://www.conventionalcommits.org/) by [semantic-release](https://semantic-release.org/).

The `version` in `package.json` is deliberately `0.0.0-development`. Git tags track released versions, and `scripts/semantic_release_workspace.js` writes the real version into the workspace manifests when it publishes, so nothing commits a version back to `main`.
